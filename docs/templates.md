# Templates

Templates are starter presets. They set default commands, ports, and route markers, but every value can be overridden from the CLI.

Every GitHub Actions workflow generated by a template is cost-aware by default: base-branch triggers, stale-run cancellation, a 10 minute timeout, and either app-scoped `paths` for monorepos or docs-only `paths-ignore` for root apps.

Templates are only for route smoke setup. For longer task proof with a final
script, logs, screenshots, and `result.json`, use
[`docs/browser-task-artifacts.md`](browser-task-artifacts.md) instead of adding
that workflow to a route template.

## `vite-app`

Default web command:

```bash
npm run dev -- --host 127.0.0.1
```

Default port: `5173`.

## `next-app`

Default web command:

```bash
npm run dev -- --hostname 127.0.0.1
```

Default port: `3000`.

## `app-plus-api`

Starts a web app and an API server through Playwright `webServer`.

Defaults:

```bash
npm run dev -- --host 127.0.0.1
PORT=3001 npm run dev:api
```

API health URL:

```text
http://127.0.0.1:3001/api/health
```

Override both values for real projects:

```bash
npx playwright-ui-smoke-kit init \
  --template app-plus-api \
  --api-command "PORT=3001 npm run api" \
  --api-url "http://127.0.0.1:3001/health"
```

## `static-site`

Default command:

```bash
node tests/static-server.mjs
```

Default port: `4173`.

The kit generates `tests/static-server.mjs`, so this template does not require `http-server` or any other external static server dependency.

## Auto-detection

When `--template` is omitted, the CLI inspects dependencies and config files:

- `next` -> `next-app`;
- `astro` -> Vite-style command on port `4321`;
- `@sveltejs/kit` -> Vite-style command on port `5173`;
- `nuxt` -> Vite-style command on port `3000`;
- `vite` or `vite.config.*` -> `vite-app`;
- otherwise `vite-app`.

## Workflow Filters

For apps at the repository root, the workflow uses `paths-ignore` for docs-only changes. For monorepos, the workflow uses `paths` so only the app directory, package files, workflow file, and explicit shared paths trigger the browser smoke.

Add shared packages with repeatable `--workflow-path`:

```bash
npx playwright-ui-smoke-kit init \
  --repo-root . \
  --app-dir apps/web \
  --workflow-path "packages/ui/**"
```

Use `--workflow-all-changes` when the app depends on broad repository state and should run for every change.
